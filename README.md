# Dart Problem Solving 

A collection of programming problems solved using **Dart** language,
covering core programming concepts and OOP principles.

---

##  Topics Covered

- Variables, Conditions & Loops
- Functions & Algorithms
- Arrays & Sorting (Bubble Sort, Selection Sort)
- Search Algorithms (Binary Search)
- OOP (Encapsulation, Inheritance, Polymorphism, Abstraction)
- Null Safety & Collections (Map, List)
- Enums

---

##  Problem Solving Approach

Each problem is solved manually without AI assistance:
1. **Understand** the problem
2. **Think** step by step
3. **Write** the solution independently
4. **Review** and improve
